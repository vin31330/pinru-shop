一、正式部署前，先不要 Push
--------------------------
建議先把你現在正式版本做一個 Commit 備份：

按 Commit to main。
這一步只在本機留下版本紀錄，不會觸發 Netlify。
先不要按 Push origin。


二、覆蓋檔案
------------
把這份 ZIP 解壓縮後，裡面的 src、public、apps-script、scripts、package.json 等檔案，
直接貼到你 GitHub Desktop 現在使用的 pinru-shop 根目錄，選擇「取代目的地中的檔案」。

注意：
- 不要刪掉你原本專案的 .git
- 不要刪掉你原本專案的 .env.local

五、包色方案要怎麼設定
----------------------
新版會在以下條件全部成立時，自動幫客人帶入所有顏色：

1. Pricing Plans 的「方案名稱」包含：包色 / 全色 / 全花色 / 全款
2. 「是否逐件選規格」= TRUE
3. 「需要件數」= 該商品顏色總數
4. Product Options 有一個規格群組名稱包含：顏色 / 花色 / 色系 / 色號
5. 該規格群組的顏色數量必須剛好等於方案需要件數

例如商品有 4 色：紅、黃、藍、綠

Pricing Plans：
方案名稱：四色包色
需要件數：4
方案價格：填包色總價
是否逐件選規格：TRUE
顯示狀態：TRUE

Product Options：
顏色 / 紅
顏色 / 黃
顏色 / 藍
顏色 / 綠

客人選「四色包色」後，網站會直接顯示：
第1件 紅
第2件 黃
第3件 藍
第4件 綠
不用再一個一個選。

顏色的自動排列順序，就是 Product Options 的「顯示順序」。
